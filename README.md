# ps4-jb
Launcher do PS4 FW 13.52 (GoldHEN) oparty na oficjalnym hoście WebKitty. Nie zawiera kodu exploitów.

## Po włączeniu konsoli
1. Przeglądarka PS4 → zakładka z tą stroną (GitHub Pages).
2. "Jailbreak + GoldHEN" → wybierz GoldHEN.
3. Zakładka Tools → "Disable Updates" (blokada automatycznych aktualizacji).
4. Normalnie uruchamiaj gry.

## Pliki
- `index.html` - strona-zakładka (przycisk do hosta WebKitty i mirror).
- `scripts/send-payload.ps1` - wysyłka payloadu z PC do BinLoadera GoldHENa (port 9090).

## Stan
- Konsola: CUH-2116A, FW 13.52, GoldHEN v2.4b18.12
- Linux na PS4: testowany (działał), na razie nieużywany.
